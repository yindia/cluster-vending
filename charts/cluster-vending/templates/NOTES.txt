  kubectl -n {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w
{{- if .Values.ui.enabled }}

Console: one port-forward is enough. The browser only calls the console's
origin; the console's server side calls the API at {{ include "cv.apiBaseURL" . }}.

  kubectl -n {{ $ns }} port-forward svc/{{ include "cv.name" (dict "root" . "component" "ui") }} 3000:{{ .Values.ui.service.port }}
  open http://localhost:3000
{{- if .Values.ui.auth.enabled }}

  Login is on (ui.auth): the console requires HTTPS for {{ .Values.ui.auth.url }}.
  Use the Ingress (ui.ingress) with TLS; a plain-HTTP port-forward cannot log in.
{{- end }}
{{- end }}

  curl -s http://localhost:8080/healthz
  bin/cluster-vending --server http://localhost:8080 tenant list
